# ไพ่ทาโรต์ (Tarot web app)
เว็บไซต์แบบ static ล้วน (HTML + JS + รูปภาพ) ไม่มี backend วางบนโฮสต์ฟรีได้ทุกเจ้า (GitHub Pages, Netlify, Cloudflare Pages)
เปิดไฟล์ index.html เป็นหน้าแรก

- ภาพไพ่: Rider-Waite-Smith (Pamela Colman Smith, 1909, Public Domain) จาก github.com/mixvlad/TarotCards
- ความหมายไพ่: เขียนเป็นภาษาไทยสำหรับแอพนี้
- ฟอนต์: Chonburi และ Noto Serif Thai จาก Google Fonts
